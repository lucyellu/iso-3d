⏰ How This Clock Works

Each clock displays time as rotating concentric dials, like nested clock faces. The rings rotate to show the current time unit value aligned with the top indicator needle.

  • Rotating Dials: Each ring rotates to position the current value (second, minute, hour, etc.) at the top
